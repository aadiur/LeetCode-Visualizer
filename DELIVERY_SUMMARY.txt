✨ KEY FEATURES

Real-Time Feedback
  • Type code → see animation <100ms later
  • Live syntax highlighting
  • Debounced recomputation (no lag)

Language Agnostic
  • Same algorithm in C++, Python, Java, JS
  • Produces identical AIR events
  • Identical visualization
  • Proves algorithm understanding is syntax-independent

Semantic Clarity
  • AIR (Algorithm Intermediate Representation) layer
  • Shows what code means, not just what it does
  • LOOP_START, SWAP, ARRAY_PUSH events visible
  • Education-focused

Smooth Animations
  • 60fps, GPU-accelerated (CSS transforms)
  • Elements smoothly enter (320ms), exit (280ms), swap (400ms)
  • FLIP technique for swaps (visually accurate)
  • No choppy or jarring transitions

Time-Travel Debugging
  • Seek to any step instantly
  • No re-computation needed
  • Click gutter line → jump to first event
  • Click AIR ticket → jump to that step

Anomaly Detection
  • Infinite loop detection (backward counter, zero step)
  • Logic error warnings
  • Red banner alerts
  • Truncation flag shows when capped

Cross-Language Equivalence
  • Verified: C++, Python, Java, JavaScript
  • All 5 examples tested
  • Identical execution histories
  • Identical final states
